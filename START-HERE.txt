CREATOR HUB CREATOR NETWORK — NEXUS EDITION 6.0.2 COMPLETE SOURCE RECOVERY

This is the existing Nexus project with recovered gift assets and reconciled LIVE-room source. It is a manual-install source package; it does not deploy or change live services.

START HERE
1. Read docs/NEXUS-EDITION-6.0.2-RECOVERY.md.
2. Read docs/DEPLOYMENT-GUIDE-NEXUS-6.0.2.md and docs/LIVE-ROOM-EXPERIENCE-NEXUS-6.0.2.md.
3. Configure backend environment variables securely; never expose server secrets in frontend files.
4. Run `npm run check`.
5. Run `npm run studio:sync-android`, then run `npm run check` again.
6. Back up the target database; inspect its migration ledger/schema and validate migration 0026 in staging before production.
7. Complete the service/device acceptance checklist before production deployment.

INCLUDED
- Existing frontend, backend, database migrations, docs, Android Gradle source, iPhone web entry/PWA, and historical APK artifacts.
- Recovered local artwork, animations, sound effects, gifter badges and multi-guest SVG for the gift catalogue.
- Reconciled server-backed LIVE polls/voting, Q&A, reactions, gift-event history, host controls, analytics and optional recording management.

LIMITS
- The historical APKs are preserved but were not rebuilt/signed for 6.0.2; Android build tooling is absent in this environment.
- Real Supabase migration/RLS, LiveKit Egress/private-storage, PayPal, Render, camera/microphone and physical-device end-to-end tests remain deployment/staging checks.
- No live deployment, production database write, or real payment was performed.
