# CHL UI icon additions

These are additive, monochrome SVG icons designed for currentColor so the existing theme can control contrast. They do not replace the root `icons/` files or the gift art catalogue. Prefer visible labels for unfamiliar actions; an icon alone should not be the only source of meaning.

Use with explicit accessible names when decorative use is not appropriate, e.g. `<img src="assets/chl-icons/poll.svg" alt="Polls">`. When an SVG is inside a button, the button itself should have an accessible name; do not rely on the image's title alone.
