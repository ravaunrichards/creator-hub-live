# Creator Hub Creator Network repair package

This is an installer for the **existing** `ravaunrichards/creator-hub-live` checkout. It makes backups, checks exact source anchors, wires the existing LIVE-experience backend router, removes the six reaction counters and Run preflight button, returns actual gift metadata and enables existing same-origin gift assets, improves the hidden gift gallery/mobile LIVE layout, invalidates the old frontend cache, aligns version metadata, and installs a focused static regression test. It does not create demo data or touch production database records.

See `docs/REPAIR-4.2.0-INSTALL.md` in the target project after installation for limits and test steps.
