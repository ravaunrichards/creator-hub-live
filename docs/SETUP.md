# Setup entry point

Use `INSTALL.md` as the authoritative manual installation guide for website release 4.0.0. Use `DATABASE.md` for migration order and schema preflight, `DEPLOYMENT.md` for static website/backend hosting, `SECURITY.md` for secrets and access control, and `VALIDATION-4.0.0.md` plus `PRODUCTION-ACCEPTANCE-CHECKLIST.md` for acceptance.

This source bundle does not make production changes automatically. Back up before install, and never apply all historical migrations blindly.
