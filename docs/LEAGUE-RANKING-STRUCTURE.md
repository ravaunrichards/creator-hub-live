The legacy `A` catalog row remains only for database compatibility; it is not an official competitive division. League points, coins, diamonds, cash, and permanent team XP are separate. Verified server-side results determine standings. Promotion/relegation only follows the existing server rules; this catalog migration does not move teams or create results.

Planned seasons: Opening Season, Rising Stars, Champions League, and All-Star Season. Season activation and result approval remain administrator-controlled. The existing schema uses internal status values; do not assume the public labels `Upcoming`, `Active`, `Completed`, and `Archived` are fully wired to every screen without further contract verification.
